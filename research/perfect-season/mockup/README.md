# Perfect Season mockup source

Source of the clickable design mockup (Design canvas artifact: https://claude.ai/artifact/Ss2spn9ioCfEKnUZsT9EKa).

- `Main.dc.html`: the whole interactive prototype (home → draft → season → playoffs → results → share) in one component.
- The other `.dc.html` files are snapshot frames that mount `Main` with a `demo` preset.
- Sample data: 10 real NBA team-decades (top 9 players each) captured during research. The real game will use the data pipeline in SPEC §11.
